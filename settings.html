⚡ Software Development & DSA Architecture Overview (Project / Viva Demonstration)

Academic Prototype

1. Core Data Structures Implemented:

  • Structures (Structs / Objects): Encapsulates Employee record schema (ID, Name, Department, Shift, Joining Date, Contact).
  • Arrays: Linear contiguous memory stores for 50 employee records and ~1,500 daily attendance history punch matrices.
  • Hash Table (Linear Probing): Fixed capacity (size = 97 prime table). Implements custom polynomial ASCII hash function and linear collision resolution for $O(1)$ fast employee lookups by ID.

2. Algorithms & Operations:

  • Hash-Based Searching: $O(1)$ average time complexity with step-by-step probe tracking.
  • Sorting: QuickSort / TimSort multi-column comparator (ID, Name, Dept, Attendance %, Risk Score).
  • Rule-Based Risk Calculation: $$\text{Risk} = (100 - \text{Att \%}) \times 0.45 + (\text{Late} \times 4) + (\text{Consec Abs} \times 12) + (\text{Missed} \times 8)$$
  • Data Persistence: Full CRUD with localStorage database simulation.
